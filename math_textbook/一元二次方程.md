# 一元二次方程

一元二次方程是初中数学的重要内容，是后续学习二次函数、不等式的基础。本章介绍一元二次方程的概念、解法、判别式及其应用。

## 一元二次方程的定义

### 知识点：一元二次方程的概念

只含有一个未知数，并且未知数的最高次数是 2 的整式方程，叫做一元二次方程。

一元二次方程的一般形式为：

$$
ax^2 + bx + c = 0 \quad (a \neq 0)
$$

其中 $ax^2$ 是二次项，$a$ 是二次项系数；$bx$ 是一次项，$b$ 是一次项系数；$c$ 是常数项。

判断一个方程是否为一元二次方程，必须同时满足三个条件：
1. 是整式方程；
2. 只含有一个未知数；
3. 未知数的最高次数为 2。

示例：方程 $3x^2 - 2x + 1 = 0$ 是一元二次方程，其中 $a = 3$，$b = -2$，$c = 1$。

### 知识点：一元二次方程的根

使一元二次方程左右两边相等的未知数的值，叫做一元二次方程的根（或解）。

例如，对于方程 $x^2 - 4 = 0$，将 $x = 2$ 代入得 $4 - 4 = 0$，成立，所以 $x = 2$ 是它的根；同样 $x = -2$ 也是它的根。

一元二次方程最多有两个实数根，也可能有一个根或没有实数根。

## 一元二次方程的解法

### 知识点：直接开平方法

对于形如 $x^2 = p$（$p \geq 0$）的方程，可以直接开平方求解：

$$
x = \pm \sqrt{p}
$$

更一般地，形如 $(x + n)^2 = p$（$p \geq 0$）的方程，开平方得：

$$
x + n = \pm \sqrt{p} \quad \Rightarrow \quad x = -n \pm \sqrt{p}
$$

注意：当 $p < 0$ 时，方程没有实数根。

示例：解方程 $(x - 3)^2 = 16$。开平方得 $x - 3 = \pm 4$，所以 $x = 7$ 或 $x = -1$。

### 知识点：配方法

配方法是通过把方程配方成 $(x + n)^2 = p$ 的形式来求解的方法。

步骤如下：
1. 把二次项系数化为 1（方程两边同除以 $a$）；
2. 把常数项移到等号右边；
3. 方程两边同时加上一次项系数一半的平方；
4. 左边写成完全平方式，右边合并常数；
5. 用直接开平方法求解。

示例：解方程 $x^2 + 6x + 5 = 0$。

移项得 $x^2 + 6x = -5$，两边加上 $\left(\frac{6}{2}\right)^2 = 9$，得 $x^2 + 6x + 9 = 4$，即 $(x + 3)^2 = 4$，开方得 $x + 3 = \pm 2$，所以 $x = -1$ 或 $x = -5$。

### 知识点：公式法

用求根公式直接求解的方法。对一般形式 $ax^2 + bx + c = 0$（$a \neq 0$），求根公式为：

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

步骤：
1. 把方程化为一般形式，确定 $a$、$b$、$c$；
2. 计算判别式 $\Delta = b^2 - 4ac$；
3. 当 $\Delta \geq 0$ 时，代入公式求解；当 $\Delta < 0$ 时，方程无实数根。

示例：解方程 $2x^2 - 4x - 6 = 0$。这里 $a = 2$，$b = -4$，$c = -6$。判别式 $\Delta = (-4)^2 - 4 \times 2 \times (-6) = 16 + 48 = 64$，代入公式得 $x = \frac{4 \pm 8}{4}$，所以 $x = 3$ 或 $x = -1$。

### 知识点：因式分解法

把方程一边化为零，另一边分解成两个一次因式的乘积，从而转化为两个一元一次方程求解。

依据：若 $A \cdot B = 0$，则 $A = 0$ 或 $B = 0$。

步骤：
1. 移项，使方程右边为 0；
2. 把左边因式分解；
3. 令每个因式等于 0，分别解两个一元一次方程。

示例：解方程 $x^2 - 5x + 6 = 0$。因式分解得 $(x - 2)(x - 3) = 0$，所以 $x = 2$ 或 $x = 3$。

## 一元二次方程的判别式

### 知识点：判别式与根的关系

判别式 $\Delta = b^2 - 4ac$ 用于判断一元二次方程 $ax^2 + bx + c = 0$ 根的情况：

- 当 $\Delta > 0$ 时，方程有两个不相等的实数根；
- 当 $\Delta = 0$ 时，方程有两个相等的实数根（即一个根）；
- 当 $\Delta < 0$ 时，方程没有实数根。

示例：判断方程 $x^2 - 2x + 5 = 0$ 的根的情况。$\Delta = (-2)^2 - 4 \times 1 \times 5 = 4 - 20 = -16 < 0$，所以方程没有实数根。

## 一元二次方程的应用题

### 知识点：列一元二次方程解应用题

解决实际问题的基本步骤：
1. 审题，找出题中的等量关系；
2. 设未知数；
3. 根据等量关系列出方程；
4. 解方程，并检验根是否符合实际意义；
5. 作答。

常见题型：增长率问题、面积问题、握手问题、传染问题等。

示例：某学校组织了一次篮球比赛，每两队之间都比赛一场，共赛了 45 场，求共有多少个队参赛。设有 $x$ 个队，则每队要赛 $(x-1)$ 场，但每场比赛被算了两次，所以 $\frac{x(x-1)}{2} = 45$，即 $x^2 - x - 90 = 0$，解得 $x = 10$ 或 $x = -9$（舍去），所以共有 10 个队参赛。
